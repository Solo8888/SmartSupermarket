# 推荐系统模块

## 功能说明

本模块提供个性化商品推荐功能，包括：

1. **个性化推荐API** (`/recommendations/personalized`) - 基于用户历史行为的推荐
2. **新用户推荐API** (`/recommendations/new-user`) - 无需登录的推荐

## 推荐算法

### 核心算法

推荐系统采用基于规则的混合推荐算法，主要考虑以下因素：

#### 1. 商品得分计算

每个商品的推荐得分由以下因素加权计算：

| 因素 | 权重 | 计算方法 | 说明 |
|------|------|----------|------|
| 销量分数 | 0.3 | min(销量/100, 1.0) * 0.3 | 销量越高，分数越高 |
| 浏览量分数 | 0.2 | min(浏览量/200, 1.0) * 0.2 | 浏览量越高，分数越高 |
| 库存分数 | 0.2 | min(库存/100, 1.0) * 0.2 | 库存充足的商品优先 |
| 促销分数 | 0.3 | 有促销活动加0.3分 | 促销商品优先 |
| 用户偏好分数 | 0.2 | 偏好分类商品加0.2分 | 仅对登录用户生效 |

#### 2. 新用户推荐策略

对于新用户（无购买历史），推荐策略如下：

1. 过滤掉库存为0的商品
2. 计算每个商品的基础得分（销量、浏览量、库存、促销）
3. 按得分从高到低排序
4. 返回前N个商品

#### 3. 个性化推荐策略

对于老用户（有购买历史），推荐策略如下：

1. 过滤掉库存为0的商品
2. 分析用户的购买历史，确定偏好分类
3. 计算每个商品的得分（基础得分 + 用户偏好得分）
4. 按得分从高到低排序
5. 返回前N个商品

### 技术实现

1. **用户行为分析**：通过查询用户的订单历史，分析用户偏好的商品分类
2. **商品评分**：综合考虑商品的销量、浏览量、库存和促销状态
3. **结果排序**：按计算出的推荐分数排序，返回最相关的商品
4. **门店过滤**：支持按门店ID过滤推荐结果

## API接口

### 1. 个性化推荐接口

**URL**: `POST /recommendations/personalized`

**请求体**:
```json
{
  "store_id": "可选，门店ID",
  "limit": 20
}
```

**响应**:
```json
{
  "products": [
    {
      "id": "商品ID",
      "name": "商品名称",
      "category_id": "分类ID",
      "store_id": "门店ID",
      "price": 99.99,
      "original_price": 129.99,
      "description": "商品描述",
      "image_url": "图片URL",
      "stock": 100,
      "sales_count": 500,
      "view_count": 1000,
      "score": 0.95,
      "reason": "热销商品，促销商品"
    }
  ],
  "total": 20,
  "algorithm": "personalized",
  "explanation": "基于用户历史行为和商品热度的个性化推荐"
}
```

### 2. 新用户推荐接口

**URL**: `GET /recommendations/new-user`

**参数**:
- `store_id` (可选): 门店ID
- `limit` (可选): 推荐商品数量，默认20

**响应**:
```json
{
  "products": [
    {
      "id": "商品ID",
      "name": "商品名称",
      "category_id": "分类ID",
      "store_id": "门店ID",
      "price": 99.99,
      "original_price": 129.99,
      "description": "商品描述",
      "image_url": "图片URL",
      "stock": 100,
      "sales_count": 500,
      "view_count": 1000,
      "score": 0.95,

  "algorithm": "new_user",
  "explanation": "基于热门商品、促销活动和库存情况的综合推荐"
```

## 部署说明

推荐系统作为后端服务的一部分，随FastAPI应用一起部署在Docker容器中。无需额外配置。

## 性能优化

1. **缓存机制**：建议在生产环境中为推荐结果添加缓存，减少数据库查询
2. **异步处理**：推荐计算可以在后台异步执行，提高响应速度
3. **批量查询**：优化数据库查询，减少N+1查询问题

## 扩展建议

1. **协同过滤**：实现基于用户的协同过滤算法，提高推荐准确性
2. **内容过滤**：基于商品属性的推荐算法
3. **实时推荐**：根据用户实时行为调整推荐结果
4. **A/B测试**：通过A/B测试评估不同推荐算法的效果
